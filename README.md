# Naol Video Editing Roadmap v2

A Next.js roadmap for learning video editing through directed resources, practice, projects, professional workflow, and a money path.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this repository into Vercel. Next.js is supported with zero-config deployment.

## Curriculum philosophy

Learn → Practice → Build → Prove.

The roadmap uses Kdenlive as the current editing tool while teaching transferable editing theory first.
